### OpenDev কী?

OpenDev হল OpenCode-এর একটি ব্যক্তিগত ভ্যারিয়েন্ট, একটি ওপেন সোর্স এআই কোডিং এজেন্ট যা আপনার
টার্মিনালে চলে। এটি OpenCode কোডবেসের উপর ভিত্তি করে তৈরি, আমার কাজের পদ্ধতির সাথে মানানসই
স্থানীয় পরিবর্তন এবং কনফিগারেশন সহ।

সম্পূর্ণ মূল ফিচার সেট, ডকুমেন্টেশন এবং কমিউনিটির জন্য দেখুন
[**OpenCode**](https://github.com/anomalyco/opencode) এবং এর ডক্স [**opencode.ai**](https://opencode.ai/docs)।

### ইনস্টলেশন

OpenDev [Bun](https://bun.sh) দিয়ে সোর্স থেকে চলে।

```bash
# ডিপেন্ডেন্সি ইনস্টল করুন
bun install

# ডেভ সার্ভার চালান
bun dev
```

মূল বাইনারি ইনস্টল (অপরিবর্তিত OpenCode) এর জন্য [অফিসিয়াল ইনস্টলার](https://opencode.ai/install) দেখুন।

### বিল্ট-ইন এজেন্ট

OpenCode-এর মতো, এই ভ্যারিয়েন্টে `Tab` কী দিয়ে স্যুইচ করা যায় এমন দুটি বিল্ট-ইন এজেন্ট রয়েছে।

- **build** - ডেভেলপমেন্ট কাজের জন্য ডিফল্ট, সম্পূর্ণ অ্যাক্সেস এজেন্ট
- **plan** - বিশ্লেষণ এবং কোড অন্বেষণের জন্য রিড-অনলি এজেন্ট

OpenCode এজেন্ট সম্পর্কে আরও জানুন: [opencode.ai/docs/agents](https://opencode.ai/docs/agents)।

### ডকুমেন্টেশন

[**opencode.ai/docs**](https://opencode.ai/docs)।
