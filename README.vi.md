### OpenDev là gì?

OpenDev là một biến thể cá nhân của OpenCode, một tác nhân viết mã AI mã nguồn mở chạy trong
terminal của bạn. Nó được xây dựng trên mã nguồn OpenCode với các sửa đổi cục bộ và cấu hình
điều chỉnh theo cách tôi làm việc.

Để biết đầy đủ tính năng, tài liệu và cộng đồng của bản gốc, hãy xem
[**OpenCode**](https://github.com/anomalyco/opencode) và tài liệu tại [**opencode.ai**](https://opencode.ai/docs).

### Cài đặt

OpenDev chạy từ mã nguồn bằng [Bun](https://bun.sh).

```bash
# Cài đặt các dependency
bun install

# Chạy dev server
bun dev
```

Để cài đặt bản binary của bản gốc (OpenCode không chỉnh sửa), xem [trình cài đặt chính thức](https://opencode.ai/install).

### Các tác nhân tích hợp

Giống như OpenCode, biến thể này gồm hai tác nhân tích hợp mà bạn có thể chuyển đổi bằng phím `Tab`.

- **build** - Tác nhân mặc định có toàn quyền truy cập cho công việc phát triển
- **plan** - Tác nhân chỉ đọc để phân tích và khám phá mã nguồn

Tìm hiểu thêm về các tác nhân của OpenCode tại [opencode.ai/docs/agents](https://opencode.ai/docs/agents).
