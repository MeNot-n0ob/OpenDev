### Šta je OpenDev?

OpenDev je lična varijanta OpenCode-a, open source AI agenta za kodiranje koji radi u vašem
terminalu. Zasnovan je na OpenCode kodu sa lokalnim modifikacijama i konfiguracijom prilagođenom
mom načinu rada.

Za kompletan skup funkcija, dokumentaciju i zajednicu, pogledajte
[**OpenCode**](https://github.com/anomalyco/opencode) i njegovu dokumentaciju na [**opencode.ai**](https://opencode.ai/docs).

### Instalacija

OpenDev se pokreće iz izvornog koda pomoću [Bun](https://bun.sh).

```bash
# Instaliraj zavisnosti
bun install

# Pokreni razvojni server
bun dev
```

Za binarne instalacije originala (nepromijenjeni OpenCode), pogledajte [službeni instalacioni program](https://opencode.ai/install).

### Ugrađeni agenti

Kao i OpenCode, ova varijanta uključuje dva ugrađena agenta između kojih se prebacujete tipkom `Tab`.

- **build** - Podrazumijevani agent s potpunim pristupom za razvojni rad
- **plan** - Agent samo za čitanje za analizu i istraživanje koda

Saznajte više o OpenCode agentima na [opencode.ai/docs/agents](https://opencode.ai/docs/agents).
