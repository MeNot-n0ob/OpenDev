### ما هو OpenDev؟

OpenDev هو إصدار شخصي من OpenCode، وكيل برمجة ذكي مفتوح المصدر يعمل في الطرفية. يعتمد على قاعدة كود OpenCode مع تعديلات محلية وإعدادات مخصصة لطريقتي في العمل.

للحصول على قائمة الميزات الكاملة والمستندات والمجتمع، راجع [**OpenCode**](https://github.com/anomalyco/opencode) ووثائقها على [**opencode.ai**](https://opencode.ai/docs).

### التثبيت

يعمل OpenDev من المصدر باستخدام [Bun](https://bun.sh).

```bash
# تثبيت التبعيات
bun install

# تشغيل خادم التطوير
bun dev
```

لمثبتات ثنائية المصدر (OpenCode دون تعديل)، راجع [المثبت الرسمي](https://opencode.ai/install).
