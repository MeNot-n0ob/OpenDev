### ما هو OpenDev؟

OpenDev هو نسخة شخصية من OpenCode، وهو وكيل برمجة بالذكاء الاصطناعي مفتوح المصدر يعمل في
الطرفية. يعتمد على كود OpenCode مع تعديلات محلية وإعدادات مُكيّفة
مع طريقة عملي.

للحصول على مجموعة الميزات الكاملة والتوثيق والمجتمع، راجع
[**OpenCode**](https://github.com/anomalyco/opencode) وتوثيقه على [**opencode.ai**](https://opencode.ai/docs).

### التثبيت

يعمل OpenDev من الكود المصدري باستخدام [Bun](https://bun.sh).

```bash
# تثبيت التبعيات
bun install

# تشغيل خادم التطوير
bun dev
```

للتثبيتات الثنائية الأصلية (OpenCode غير المعدل)، راجع [المثبّت الرسمي](https://opencode.ai/install).

### الوكالات المدمجة

مثل OpenCode، تتضمن هذه النسخة وكيلين مدمجين يمكنك التبديل بينهما بمفتاح `Tab`.

- **build** - وكيل افتراضي بصلاحية كاملة لأعمال التطوير
- **plan** - وكيل للقراءة فقط للتحليل واستكشاف الكود

تعرف على المزيد حول وكلاء OpenCode على [opencode.ai/docs/agents](https://opencode.ai/docs/agents).

### التوثيق

لمعرفة كيفية إعداد OpenCode، راجع التوثيق الأصلي على
[**opencode.ai/docs**](https://opencode.ai/docs).
