### Hva er OpenDev?

OpenDev er en personlig variant av OpenCode, en open source AI-kodingsagent som kjører i
terminalen din. Den bygger på OpenCode-koden med lokale modifikasjoner og konfigurasjon tilpasset
måten jeg jobber på.

For det fullstendige funksjonssettet, dokumentasjonen og fellesskapet, se
[**OpenCode**](https://github.com/anomalyco/opencode) og dokumentasjonen på [**opencode.ai**](https://opencode.ai/docs).

### Installasjon

OpenDev kjører fra kildekoden med [Bun](https://bun.sh).

```bash
# Installer avhengigheter
bun install

# Kjør utviklingsserveren
bun dev
```

For binære installasjoner av originalen (uendret OpenCode), se den [offisielle installatøren](https://opencode.ai/install).

### Innebygde agenter

Som OpenCode inkluderer denne varianten to innebygde agenter du kan bytte mellom med `Tab`-tasten.

- **build** - Standardagent med full tilgang for utviklingsarbeid
- **plan** - Skrivebeskyttet agent for analyse og kodeutforskning

Lær mer om OpenCode-agenter på [opencode.ai/docs/agents](https://opencode.ai/docs/agents).
