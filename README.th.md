### OpenDev คืออะไร?

OpenDev เป็นตัวแปรส่วนบุคคลของ OpenCode เอเจนต์เขียนโค้ด AI แบบโอเพนซอร์สที่ทำงานใน
เทอร์มินัลของคุณ มันสร้างบนโค้ดของ OpenCode พร้อมการปรับแต่งในเครื่องและคอนฟิกที่เหมาะกับ
วิธีการทำงานของฉัน

สำหรับฟีเจอร์ครบชุด เอกสารประกอบ และชุมชนของต้นทาง ดูได้ที่
[**OpenCode**](https://github.com/anomalyco/opencode) และเอกสารที่ [**opencode.ai**](https://opencode.ai/docs)

### การติดตั้ง

OpenDev รันจากซอร์สโค้ดด้วย [Bun](https://bun.sh)

```bash
# ติดตั้ง dependencies
bun install

# รัน dev server
bun dev
```

สำหรับการติดตั้งแบบไบนารีของต้นทาง (OpenCode ที่ไม่ผ่านการแก้ไข) ดู [ตัวติดตั้งอย่างเป็นทางการ](https://opencode.ai/install)

### เอเจนต์ในตัว

เช่นเดียวกับ OpenCode ตัวแปรนี้มีเอเจนต์ในตัวสองตัวที่คุณสามารถสลับได้ด้วยปุ่ม `Tab`

- **build** - เอเจนต์เริ่มต้นที่มีสิทธิ์เข้าถึงเต็มรูปแบบสำหรับงานพัฒนา
- **plan** - เอเจนต์แบบอ่านอย่างเดียวสำหรับวิเคราะห์และสำรวจโค้ด

เรียนรู้เพิ่มเติมเกี่ยวกับเอเจนต์ของ OpenCode ได้ที่ [opencode.ai/docs/agents](https://opencode.ai/docs/agents)

### เอกสารประกอบ

สำหรับวิธีกำหนดค่า OpenCode ดูเอกสารของต้นทางได้ที่
[**opencode.ai/docs**](https://opencode.ai/docs)
