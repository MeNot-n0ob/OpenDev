### O que é o OpenDev?

O OpenDev é uma variante pessoal do OpenCode, um agente de codificação por IA de código aberto que roda no seu
terminal. Ele se baseia no código do OpenCode com modificações locais e configuração ajustada
para o meu modo de trabalhar.

Para o conjunto completo de recursos upstream, documentação e comunidade, consulte
[**OpenCode**](https://github.com/anomalyco/opencode) e seus documentos em [**opencode.ai**](https://opencode.ai/docs).

### Instalação

O OpenDev roda a partir do código-fonte com [Bun](https://bun.sh).

```bash
# Instalar dependências
bun install

# Executar o servidor de desenvolvimento
bun dev
```

Para instalações binárias upstream (OpenCode não modificado), consulte o [instalador oficial](https://opencode.ai/install).

### Agentes integrados

Como o OpenCode, esta variante inclui dois agentes integrados entre os quais você pode alternar com a tecla `Tab`.

- **build** - Agente padrão com acesso total para trabalho de desenvolvimento
- **plan** - Agente somente leitura para análise e exploração de código

Saiba mais sobre os agentes do OpenCode em [opencode.ai/docs/agents](https://opencode.ai/docs/agents).
