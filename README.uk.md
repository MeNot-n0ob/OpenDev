### Що таке OpenDev?

OpenDev — це особистий варіант OpenCode, відкритого ІІ-агента для написання коду, який працює у вашому
терміналі. Він заснований на коді OpenCode з локальними змінами та конфігурацією, адаптованою
під мій спосіб роботи.

Повний набір функцій, документацію та спільноту дивіться в
[**OpenCode**](https://github.com/anomalyco/opencode) та його документації на [**opencode.ai**](https://opencode.ai/docs).

### Встановлення

OpenDev запускається з вихідного коду за допомогою [Bun](https://bun.sh).

```bash
# Встановлення залежностей
bun install

# Запуск сервера розробки
bun dev
```

Для бінарних встановлень оригіналу (немодифікований OpenCode) дивіться [офіційний інсталятор](https://opencode.ai/install).

### Вбудовані агенти

Як і OpenCode, цей варіант містить двох вбудованих агентів, між якими можна перемикатися клавішею `Tab`.

- **build** - Агент за замовчуванням з повним доступом для розробки
- **plan** - Агент лише для читання для аналізу та дослідження коду

Дізнайтеся більше про агентів OpenCode на [opencode.ai/docs/agents](https://opencode.ai/docs/agents).
