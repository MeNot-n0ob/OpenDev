### ¿Qué es OpenDev?

OpenDev es una variante personal de OpenCode, un agente de codificación por IA de código abierto que se ejecuta en tu
terminal. Se basa en el código de OpenCode con modificaciones locales y una configuración ajustada
a mi forma de trabajar.

Para conocer el conjunto completo de funciones del proyecto original, la documentación y la comunidad, consulta
[**OpenCode**](https://github.com/anomalyco/opencode) y su documentación en [**opencode.ai**](https://opencode.ai/docs).

### Instalación

OpenDev se ejecuta desde el código fuente con [Bun](https://bun.sh).

```bash
# Instalar dependencias
bun install

# Ejecutar el servidor de desarrollo
bun dev
```

Para las instalaciones binarias del proyecto original (OpenCode sin modificar), consulta el
[instalador oficial](https://opencode.ai/install).

### Agentes integrados

Al igual que OpenCode, esta variante incluye dos agentes integrados entre los que puedes cambiar con la tecla `Tab`.

- **build** - Agente predeterminado con acceso completo para el trabajo de desarrollo
- **plan** - Agente de solo lectura para análisis y exploración de código

Obtén más información sobre los agentes de OpenCode en [opencode.ai/docs/agents](https://opencode.ai/docs/agents).
