### Что такое OpenDev?

OpenDev — это личный вариант OpenCode, опенсорсного ИИ-агента для написания кода, который работает в вашем
терминале. Он основан на коде OpenCode с локальными изменениями и конфигурацией, адаптированной
под мой способ работы.

Полный набор функций, документацию и сообщество смотрите в
[**OpenCode**](https://github.com/anomalyco/opencode) и его документации на [**opencode.ai**](https://opencode.ai/docs).

### Установка

OpenDev запускается из исходного кода с помощью [Bun](https://bun.sh).

```bash
# Установка зависимостей
bun install

# Запуск сервера разработки
bun dev
```

Для бинарных установок оригинала (немодифицированный OpenCode) смотрите [официальный установщик](https://opencode.ai/install).

### Встроенные агенты

Как и OpenCode, этот вариант включает двух встроенных агентов, между которыми можно переключаться клавишей `Tab`.

- **build** - Агент по умолчанию с полным доступом для разработки
- **plan** - Агент только для чтения для анализа и исследования кода

Узнайте больше об агентах OpenCode на [opencode.ai/docs/agents](https://opencode.ai/docs/agents).
