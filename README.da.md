### Hvad er OpenDev?

OpenDev er en personlig variant af OpenCode, en open source AI-kodningsagent, der kører i din
terminal. Den bygger på OpenCode-koden med lokale ændringer og konfiguration tilpasset
den måde, jeg arbejder på.

For det fulde funktionssæt, dokumentation og fællesskab, se
[**OpenCode**](https://github.com/anomalyco/opencode) og dets dokumentation på [**opencode.ai**](https://opencode.ai/docs).

### Installation

OpenDev kører fra kildekoden med [Bun](https://bun.sh).

```bash
# Installér afhængigheder
bun install

# Kør udviklingsserveren
bun dev
```

For binære installationer af originalen (uændret OpenCode), se den [officielle installer](https://opencode.ai/install).

### Indbyggede agenter

Som OpenCode inkluderer denne variant to indbyggede agenter, du kan skifte mellem med `Tab`-tasten.

- **build** - Standardagent med fuld adgang til udviklingsarbejde
- **plan** - Skrivebeskyttet agent til analyse og kodeudforskning

Lær mere om OpenCode-agenter på [opencode.ai/docs/agents](https://opencode.ai/docs/agents).
