### Czym jest OpenDev?

OpenDev to osobisty wariant OpenCode, open source agenta do pisania kodu opartego na AI, który działa w twoim
terminalu. Opiera się na kodzie OpenCode z lokalnymi modyfikacjami i konfiguracją dostosowaną
do mojego sposobu pracy.

Pełny zestaw funkcji, dokumentację i społeczność znajdziesz w
[**OpenCode**](https://github.com/anomalyco/opencode) oraz w jego dokumentacji na [**opencode.ai**](https://opencode.ai/docs).

### Instalacja

OpenDev działa z kodu źródłowego przy użyciu [Bun](https://bun.sh).

```bash
# Instalacja zależności
bun install

# Uruchomienie serwera deweloperskiego
bun dev
```

W przypadku instalacji binarnych oryginału (niezmodyfikowany OpenCode) zobacz [oficjalny instalator](https://opencode.ai/install).

### Wbudowani agenci

Podobnie jak OpenCode, ten wariant zawiera dwóch wbudowanych agentów, między którymi możesz przełączać się klawiszem `Tab`.

- **build** - Domyślny agent z pełnym dostępem do pracy deweloperskiej
- **plan** - Agent tylko do odczytu do analizy i eksploracji kodu

Dowiedz się więcej o agentach OpenCode na [opencode.ai/docs/agents](https://opencode.ai/docs/agents).
