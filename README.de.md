### Was ist OpenDev?

OpenDev ist eine persönliche Variante von OpenCode, einem Open-Source-KI-Coding-Agenten, der in deinem
Terminal läuft. Er baut auf dem OpenCode-Code auf, mit lokalen Änderungen und einer auf
meine Arbeitsweise abgestimmten Konfiguration.

Für das vollständige Funktionenspektrum, die Dokumentation und die Community des Originals siehe
[**OpenCode**](https://github.com/anomalyco/opencode) und die Doku unter [**opencode.ai**](https://opencode.ai/docs).

### Installation

OpenDev läuft aus dem Quellcode mit [Bun](https://bun.sh).

```bash
# Abhängigkeiten installieren
bun install

# Entwicklungsserver starten
bun dev
```

Für binäre Installationen des Originals (unverändertes OpenCode) siehe den [offiziellen Installer](https://opencode.ai/install).

### Integrierte Agenten

Wie OpenCode enthält auch diese Variante zwei integrierte Agenten, zwischen denen du mit der `Tab`-Taste wechseln kannst.

- **build** - Standard-Agent mit vollem Zugriff für Entwicklungsarbeit
- **plan** - Schreibgeschützter Agent für Analyse und Code-Exploration

Mehr über OpenCode-Agenten unter [opencode.ai/docs/agents](https://opencode.ai/docs/agents).
